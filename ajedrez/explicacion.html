Especificaciones del Sistema

Documentación técnica integral de la aplicación. El proyecto utiliza una arquitectura de Componentes React de alto rendimiento, integración WASM para el motor de ajedrez y un sistema de renderizado visual avanzado para la gestión del tablero.

{/* Columna Izquierda */}
{/* SECCIÓN 1: EXPERIENCIA VISUAL Y MECÁNICAS (NUEVO & EXTENDIDO) */}

Mecánicas de Tablero & Visuals

Motor de Arrastre Híbrido

Implementación dual de eventos TouchEvents y MouseEvents. El sistema detecta la presión y velocidad del gesto para diferenciar entre un "tap" (selección) y un "drag" (arrastre), evitando el ghosting en pantallas táctiles de alta frecuencia.

Renderizado por Capas (Z-Index)

El tablero se renderiza en tres capas independientes para optimizar el repaint:
1. Base Layer: Casillas y coordenadas (Estático).
2. Highlight Layer: Indicadores de último movimiento y casillas válidas.
3. Piece Layer: Sprites SVG de las piezas con propiedades `will-change: transform`.

Animaciones de Interpolación

Las piezas no "saltan" de una casilla a otra. Se utiliza una interpolación CSS `cubic-bezier(0.4, 0, 0.2, 1)` para suavizar el movimiento (150ms), calculando el delta (X,Y) desde la posición de origen para una transición fluida.

{/* SECCIÓN 2: MOTOR DE AJEDREZ */}

Backend Lógico (Engine)

  • WASM Stockfish 16+

    Ejecución de binarios compilados a WebAssembly. Permite evaluaciones de profundidad 20+ en milisegundos.

  • Thread Isolation

    Uso estricto de Web Workers para aislar el cálculo computacional del hilo principal de renderizado.

{/* Columna Derecha */}
{/* SECCIÓN 3: INTERFAZ DE USUARIO (UI/UX) - EXTENDIDO */}

Interfaz y Accesibilidad

Feedback Háptico y Sonoro

Implementación de la API `Navigator.vibrate()` para feedback táctil en móviles al realizar capturas o jaques, sincronizado con efectos de sonido espaciales (Web Audio API).

Sistema de Temas Dinámicos

Soporte para cambio en caliente de skins de tablero (Madera, Mármol, Neon) y sets de piezas (Staunton, Pixel, 3D), utilizando variables CSS y SVG masks para coloreado dinámico.

Diseño Responsivo Líquido

El tablero mantiene su relación de aspecto (1:1) mediante `aspect-ratio` CSS, ajustándose dinámicamente al viewport vertical u horizontal sin desbordamiento.

{/* SECCIÓN 4: ANALÍTICA */}

Analítica y Datos

  • Blunder Detection Algorithm

    Comparativa de delta-cp (centipawn loss) pre y post movimiento para categorizar jugadas: Brillante, Mejor, Imprecisión, Error y Error Grave.

  • Exportación PGN Avanzada

    Generación de metadatos completos incluyendo marcas de tiempo por movimiento (`%clk`) y anotaciones NAG (`$1`, `$2`).

{/* SECCIÓN 5: REGLAS */}

Validación Normativa

Validación estricta FIDE (En Passant, Regla 50 movimientos, Triple repetición, Coronación) gestionada por librería de estados finitos.
