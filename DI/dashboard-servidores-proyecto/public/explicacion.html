1. Arquitectura & Flujo de Datos

El sistema utiliza una arquitectura Cliente-Servidor desacoplada. El objetivo es permitir que una interfaz web (HTML5/CSS3) controle recursos del sistema operativo, algo imposible para un navegador por sí solo.

C. Almacenamiento & Persistencia

Actualmente, el sistema utiliza Memoria Volátil (RAM) para el estado (`systemStatus`).

  • Backend: Variables globales en Node.js mantienen el estado mientras el servidor corre.
  • Persistencia Futura: Para una versión v3.0, se integraría SQLite o un archivo JSON local para guardar el historial de estadísticas y logs entre reinicios.
