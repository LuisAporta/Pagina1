Cómo funciona el Dashboard

Documentación técnica y desglose del código

1. El Backend (Node.js)

El cerebro de la aplicación es server.js. Utilizamos Express para crear el servidor y child_process para ejecutar comandos reales del sistema operativo Windows.

[FOTO: Captura del editor mostrando server.js o diagrama del servidor]

Fig 1. Estructura básica del servidor Node.js

Ejecución de Comandos (Sin Relleno)

Una parte clave es cómo obtenemos la información del sistema. No usamos librerías complejas, sino comandos nativos de Windows como wmic para obtener datos reales.

app.get('/api/ram', (req, res) => { // Comando directo al sistema operativo let comando = 'wmic OS get FreePhysicalMemory'; exec(comando, (error, stdout) => { res.send(stdout); }); });

2. El Frontend (Vanilla JS)

Para la interfaz, seguimos la regla de "Don Viejo": Cero Frameworks. Usamos Javascript puro para manipular el DOM y hacer las peticiones al servidor.

El Semáforo en Tiempo Real

La interfaz consulta periódicamente el estado. Si el servidor responde OK, añadimos la clase CSS .green para el efecto neón.

function actualizarSemaforo() { fetch('/status') .then(data => { if (data.status === 'ok') { light.classList.add('green'); // Efecto Neón Verde } else { light.classList.add('red'); // Alerta Roja } }); }

3. Diseño Premium

El estilo visual busca un acabado profesional utilizando:

  • Glassmorphism: Fondos semitransparentes con desenfoque.
  • Neumorphism (Luces): Sombras y brillos externos (box-shadow) para simular luces de neón.
