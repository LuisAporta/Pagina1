Identificación Técnica del Sistema

A continuación se detallan los componentes nucleares de la aplicación y el código responsable de cada función:

Base de Datos (PostgreSQL)

Esquema relacional gestionado via Supabase.

  • Archivo: db_setup.sql
  • Tablas: profiles (líquido), transactions (movimientos).
  • Lógica: Trigger on_transaction_change para cálculo automático de saldo.

Manejo de Archivos

Almacenamiento de comprobantes en la nube.

  • Servicio: Supabase Storage (Bucket: receipts).
  • Código: Functión en transactions.html (líneas ~206-214) usando storage.from().upload().
  • Seguridad: Políticas RLS en SQL para acceso privado por usuario.

Backend & Auth

Lógica de servidor y control de acceso.

  • Auth: Supabase Auth (Manejado en login.html y common.js).
  • Sesiones: Persistencia via localStorage (finance_session).
  • Conectividad: js/config.js centraliza las credenciales API.

Lógica de Negocio

Procesamiento de datos y analíticas.

  • Gráficas: Chart.js en dashboard.html.
  • Divisas: Integración con Exchangerate-API.
  • CRUD: Funciones loadTransactions y saveTx en páginas HTML.
