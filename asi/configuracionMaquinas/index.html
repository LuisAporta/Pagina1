El Corazón: Módulo SOM

El módulo Orin Nano se encuentra bajo este disipador pasivo de gran tamaño (negro). Aquí reside la CPU ARM Cortex-A78AE y la GPU Ampere.

Conectividad I/O

  • 4x USB 3.2 Gen 2 (10Gbps)
  • 1x Gigabit Ethernet (RJ45)
  • 1x DisplayPort 1.2
  • 1x USB-C (para Device Mode)

Almacenamiento NVMe

En la parte inferior encontramos dos slots M.2 Key M para SSDs NVMe. El sistema operativo arranca desde uno de estos discos o desde el adaptador microSD (según configuración).
