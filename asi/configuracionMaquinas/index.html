Hardware & Unboxing

Unboxing

Presentación oficial del Developer Kit. La caja incluye la placa base con el módulo SOM preinstalado, fuente de alimentación DC y guía de inicio rápido.

El Corazón: Módulo SOM

El módulo Orin Nano se encuentra bajo este disipador pasivo de gran tamaño (negro). Aquí reside la CPU ARM Cortex-A78AE de 6 núcleos y la GPU Ampere con 1024 núcleos CUDA.

Conectividad I/O

  • 4x USB 3.2 Gen 2 (10Gbps) para periféricos de alta velocidad.
  • 1x Gigabit Ethernet (RJ45) para conexión de red robusta.
  • 1x DisplayPort 1.2 para salida de video 4K.
  • 1x USB-C para modo dispositivo y depuración.

Almacenamiento y M.2

Vista inferior de la placa portadora. Se aprecian los dos slots M.2 Key M para SSDs NVMe (2280) y el módulo inalámbrico M.2 Key E. El sistema operativo arranca desde la microSD (vía adaptador) o directamente desde un NVMe.
